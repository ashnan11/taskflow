# TaskFlow — Premium To-Do App

A production-ready productivity web application built with React, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- Full task CRUD with priorities, categories, tags, subtasks, notes, and recurrence
- Dashboard with productivity stats and weekly chart
- Views: Today, Upcoming, Important, Completed, Archived, Calendar, Projects, Tags
- Search, filter, and sort
- Drag-and-drop reordering
- Bulk actions with undo
- Dark/light/system theme
- Focus mode and Pomodoro timer
- Keyboard shortcuts
- localStorage persistence

## Quick Start

```bash
cd taskflow
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
npm run preview
```
